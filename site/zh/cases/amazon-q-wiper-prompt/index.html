发生了什么

一个恶意拉取请求将指示AI代理擦除本地文件和AWS资源的提示词混入了经签名的Q扩展版本；由于格式错误，该提示词未能执行。

影响: 恶意提示词被分发至一个安装量超过95万的扩展；亚马逊称该提示词格式有误，没有客户资源受到影响

谁发起了攻击

行为者: 使用GitHub别名lkmanka58的身份不明黑客

归因: 在接受404 Media采访时自行承认（称目的是揭露'AI安全作秀'）；亚马逊未公开归因其身份

动机: 展示AI供应链控制薄弱；攻击者称无意造成实际损害

如何发生

攻击途径: 向开源仓库aws-toolkit-vscode提交的commit插入了破坏性自然语言提示词，并随经签名的1.84.0版本发布

根本原因: 公开仓库的访问控制和代码审查不足，使一个未知账户得以植入提示词载荷，随后被打包签名而未被发现

时间线

  1. 2025年7月13日账户lkmanka58向亚马逊的GitHub仓库提交恶意提示词
  2. 2025年7月17日Amazon Q Developer for VS Code 1.84.0版本携带擦除提示词发布
  3. 2025年7月23日404 Media报道此次入侵；亚马逊承认并下架该版本
  4. 2025年7月24日亚马逊发布干净的1.85.0版本并撤销被泄露的凭据

应对

亚马逊下架1.84.0版本，撤销并更换凭据，发布1.85.0版本，并表示已缓解一起针对两个开源仓库已知问题的利用企图

当前状态: 已解决
