发生了什么

mcp-server-sequential-thinking、mcp-server-github、mcp-server-git和mcp-server-figma等无作用域包模仿官方MCP服务器，在安装时将主机名、工作目录和平台数据发送到一个Cloudflare Workers端点。

影响: 任何安装或运行这些包的机器都泄露了主机标识；未记录凭据窃取

谁发起了攻击

行为者: 未知（自称金丝雀研究）

归因: 作者的README将这些包定性为金丝雀研究；由Amazon Inspector和ReversingLabs报告，并被OpenSSF记录为恶意

动机: 自称为研究；行为与未经同意侦察开发者机器相符

如何发生

攻击途径: 开发者和AI代理通过npx调用的无作用域包名；postinstall钩子和bin入口都会执行index.js

根本原因: 有作用域的官方MCP包与无作用域仿冒包之间的名称混淆；安装时脚本自动执行

时间线

  1. 2026年6月9日针对仿冒MCP包发布MAL-2026-5484及相关公告
  2. 2026年9月24日公告最后更新

应对

OSV建议将受影响机器视为已被攻陷并轮换机密；这些包在OpenSSF恶意包仓库中被标记

当前状态: 已解决
