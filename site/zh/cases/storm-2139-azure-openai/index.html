微软点名Storm-2139成员：用窃取密钥劫持Azure OpenAI

发生了什么

微软修改诉状，点名一个团伙中的四名成员，该团伙利用抓取到的客户API密钥访问Azure OpenAI、绕过安全护栏、转售访问权限并生成有害图像。

影响: 微软客户的Azure OpenAI账户被未经授权使用，安全护栏被绕过以生成包括名人在内的有害图像；访问权限被转售给终端用户；财务损失未披露

谁发起了攻击

行为者: Storm-2139（Arian Yadegarnia、Alan Krysiak、Ricky Yuen、Phat Phung Tan）

归因: 由微软数字犯罪部门在修订后的民事诉状（弗吉尼亚州东区法院）中点名；成员分别位于伊朗、英国、香港和越南

动机: 转售对生成式AI服务的非法访问权限，并生成有害或未经同意的图像

如何发生

攻击途径: 从公开来源抓取客户的Azure OpenAI API密钥，配合自制的de3u工具和反向代理绕过安全护栏并转售访问权限

根本原因: 客户在公开代码和配置中泄露API密钥；仅凭密钥即可访问，使滥用行为得以持续直至异常用量被发现

时间线

  1. 2024年7月微软发现有人通过de3u工具滥用被盗的Azure OpenAI API密钥
  2. 2024年12月微软数字犯罪部门在弗吉尼亚州东区法院对10名匿名被告提起诉讼；法院批准查封一个关键域名
  3. 2025年1月诉讼文件解封；Storm-2139成员据称以人肉搜索微软律师作为回应
  4. 2025年2月27日微软修改诉状，点名四名个人（Fiz、Drago、cg-dot、Asakuri）

应对

微软撤销了访问权限、增加安全对策、查封de3u网站、提起民事诉讼并将案件移交执法部门

当前状态: 进行中
