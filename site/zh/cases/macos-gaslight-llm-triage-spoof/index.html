发生了什么

SentinelOne 描述了一个与朝鲜相关的 Rust 后门，其中包含 38 条伪造的系统消息，旨在欺骗 LLM 分诊框架，以隐藏凭据窃取程序和 Telegram C2。

影响: 未知；该植入程序隐藏了一个凭据窃取程序和 Telegram C2。

谁发起了攻击

行为者: 与朝鲜相关的行为者

归因: SentinelOne Labs 将该植入程序描述为与朝鲜相关。

动机: 规避 AI 辅助分析并窃取凭据

如何发生

攻击途径: 在 macOS Rust 植入程序中内嵌伪造的系统消息（提示注入）

根本原因: LLM 分诊框架可被嵌入在待分析样本中的指令所操控。
