Ce qui s’est passé

Check Point Research a constaté que le conteneur Python supposément hors ligne de ChatGPT pouvait joindre Internet via DNS, si bien qu'un seul prompt malveillant ou GPT personnalisé pouvait exfiltrer messages et fichiers ou ouvrir un shell distant. OpenAI a corrigé

Impact: Exfiltration silencieuse de données de conversation, y compris des contenus de santé et financiers ; aucune exploitation signalée

Qui l’a déclenché

Acteur: Check Point Research

Attribution: Divulgation responsable ; OpenAI a indiqué avoir identifié le problème en interne

Mobile: Recherche en sécurité

Comment c’est arrivé

Vecteur d’attaque: Injection de prompt amenant l'environnement à encoder des données dans des requêtes de sous-domaines DNS ; les réponses DNS rapportaient des commandes

Cause racine: La résolution DNS restait activée dans un bac à sable décrit comme sans accès réseau sortant

Chronologie

  1. 20 févr. 2026Correctif d'OpenAI entièrement déployé
  2. 30 mars 2026Check Point publie sa recherche

Réponse

OpenAI a fermé le canal DNS dans l'environnement d'exécution de code

Statut actuel: Corrigé
