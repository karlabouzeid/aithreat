Ce qui s’est passé

404 Media rapporte qu'une personne a intégré une injection de prompt dans un acte judiciaire demandant à l'IA de lui donner raison. Les détails sur le tribunal, la juridiction et l'issue ne figurent pas dans le résumé.

Impact: Inconnu ; le résumé ne dit pas si une IA a été influencée ni si une décision a été affectée.

Qui l’a déclenché

Acteur: Plaideur individuel inconnu

Attribution: Rapporté par 404 Media ; la personne n'est pas nommée dans le titre.

Mobile: Biaiser en sa faveur la relecture assistée par IA de l'acte.

Comment c’est arrivé

Vecteur d’attaque: Instructions cachées intégrées dans un document juridique lu par une IA

Cause racine: Les outils d'IA traitent comme des commandes les instructions intégrées dans le contenu des documents.
