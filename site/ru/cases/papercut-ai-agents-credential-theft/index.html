Сотни ИИ-агентов эксплуатируют серверы PaperCut NG/MF для кражи учётных данных Windows

Злоумышленник, предположительно русскоязычный, использовал сотни ИИ-агентов для эксплуатации серверов PaperCut NG/MF, кражи учётных данных Windows и организации многократно используемого внутреннего доступа. GreyNoise обнаружила 440 скомпрометированных экземпляров.

Что произошло

Злоумышленник, предположительно русскоязычный, использовал сотни ИИ-агентов для эксплуатации серверов PaperCut NG/MF, кражи учётных данных Windows и организации многократно используемого внутреннего доступа. GreyNoise обнаружила 440 скомпрометированных экземпляров.

Последствия: Не менее 440 скомпрометированных экземпляров в 395 организациях из 48 стран с многократно используемым доступом к внутренним сетям.

Кто стоит за инцидентом

Субъект: Предположительно русскоязычный злоумышленник

Атрибуция: GreyNoise оценивает злоумышленника как предположительно русскоязычного; конкретная группировка не названа.

Мотив: Неизвестен; кража учётных данных и постоянный доступ к внутренним сетям

Как это произошло

Вектор атаки: ИИ-агенты массово эксплуатируют серверы PaperCut NG/MF, а затем собирают учётные данные Windows.

Первопричина: Доступные извне уязвимые серверы PaperCut NG/MF; конкретная уязвимость в сводке не указана.
