Досье openai-dprk-korean-c2-phishingИИ-операции госакторов7 окт. 2025Южная Корея

Связанный с Северной Кореей кластер использовал ChatGPT для создания C2-инструментария в фишинге против дипломатов Сеула

Корейскоязычные учётные записи, связанные с известными фишинговыми кампаниями КНДР против южнокорейских дипломатов, использовали ChatGPT для разработки C2-вредоносного ПО, расширений для macOS, конфигураций VPN для Windows Server и инструментов кражи учётных данных.

Что произошло

Корейскоязычные учётные записи, связанные с известными фишинговыми кампаниями КНДР против южнокорейских дипломатов, использовали ChatGPT для разработки C2-вредоносного ПО, расширений для macOS, конфигураций VPN для Windows Server и инструментов кражи учётных данных.

Последствия: Инструментарий для активной дипломатической фишинговой кампании; компрометации жертв не подсчитаны.

Кто стоит за инцидентом

Субъект: Связанный с Северной Кореей фишинговый кластер

Атрибуция: OpenAI сопоставила кластер с публично описанными кампаниями КНДР против южнокорейских дипломатических целей.

Мотив: Шпионаж

Как это произошло

Вектор атаки: Разработка C2-инфраструктуры с помощью LLM и преобразование браузерных расширений для фишинга

Первопричина: Запросы в стиле разработчика на код C2 и расширений по отдельности не блокировались

Хронология

  1. окт. 2025The Hacker News и ThaiCERT передают атрибуцию к КНДР
  2. 7 окт. 2025OpenAI приостанавливает учётные записи и публикует случай

Реагирование

Учётные записи приостановлены; OpenAI поделилась результатами с партнёрами.
