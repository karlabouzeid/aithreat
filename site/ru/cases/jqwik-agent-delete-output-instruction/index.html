Что произошло

По данным Ars Technica, нераскрытое дополнение к библиотеке jqwik содержало инструкции, адресованные ИИ-агентам для программирования и предписывающие им удалять вывод приложения.

Последствия: Агентов можно было склонить к удалению вывода приложения. Число затронутых пользователей не указано.

Кто стоит за инцидентом

Субъект: Неизвестен

Атрибуция: В описании не говорится, кто добавил инструкции.

Мотив: Неизвестен

Как это произошло

Вектор атаки: Нераскрытое дополнение к проекту jqwik с инструкциями, которые ИИ-агенты для программирования читают и могут выполнить.

Первопричина: Адресованные агентам инструкции, встроенные в зависимость, которую агенты для программирования могут воспринимать как доверенный ввод.
