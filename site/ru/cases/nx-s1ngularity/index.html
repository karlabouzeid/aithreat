s1ngularity: троянизированные пакеты Nx используют CLI Claude и Gemini для кражи секретов

Вредоносные релизы Nx в npm запускали локальные ИИ-инструменты для программирования с флагами обхода разрешений для инвентаризации секретов, а затем сливали тысячи учётных данных разработчиков в публичные репозитории GitHub.

Что произошло

Вредоносные релизы Nx в npm запускали локальные ИИ-инструменты для программирования с флагами обхода разрешений для инвентаризации секретов, а затем сливали тысячи учётных данных разработчиков в публичные репозитории GitHub.

Последствия: Утекли более 2 000 секретов и 20 000 файлов примерно от 1 000 разработчиков; 480 учётных записей и около 6 700 приватных репозиториев сделаны публичными; по данным Wiz, всего затронуто 2 180 учётных записей

Кто стоит за инцидентом

Субъект: Неизвестный злоумышленник, атаковавший цепочку поставок (s1ngularity)

Атрибуция: Публичной атрибуции нет; анализ проведён мейнтейнерами Nx, Wiz, StepSecurity, Socket и GitHub Security Lab

Мотив: Массовая кража секретов разработчиков (токены GitHub и npm, SSH-ключи, криптокошельки, облачные учётные данные)

Как это произошло

Вектор атаки: Вредоносный скрипт postinstall в релизах Nx 20.9.0 — 21.8.0 в npm запускал CLI Claude, Gemini и Q с флагами обхода разрешений для поиска секретов, а затем отправлял их в публичные репозитории GitHub

Первопричина: Workflow GitHub Actions в Nx, использовавший pull_request_target с несанитизированным заголовком PR, позволил злоумышленнику украсть токен публикации npm из устаревшей ветки

Хронология

  1. 21 авг. 2025Уязвимый workflow добавлен в репозиторий Nx; откачен в master, но сохраняется в устаревшей ветке
  2. 26 авг. 2025Злоумышленник публикует троянизированные версии Nx в npm; вредоносное ПО запускает ИИ-CLI и сливает секреты в течение нескольких часов
  3. 27 авг. 2025Nx отзывает вредоносные версии, аннулирует токены и публикует бюллетень GHSA-cxm3-wv7p-598c
  4. 28 авг. 2025Вторая фаза: украденные токены GitHub использованы для перевода около 6 700 приватных репозиториев в публичные в 480 учётных записях
  5. 9 сен. 2025Wiz сообщает о 2 180 затронутых учётных записях и 7 200 репозиториях в трёх фазах

Реагирование

Nx отозвала токены npm, удалила пакеты, ввела обязательную 2FA и trusted publishing; GitHub удалил репозитории с утёкшими данными; жертвам рекомендовано сменить все учётные данные

Текущий статус: Локализован
