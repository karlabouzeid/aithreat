وجدت دراسة أجرتها Truffle Security على مدى أربع سنوات 64,024 مفتاح AWS فريدا في مصادر عامة، منها 9,300 ما زالت صالحة؛ وشكلت مستودعات Hugging Face 8,482 حالة كشف، وكان 17.9 بالمئة منها مفاتيح جذر (root).

الأثر: أكثر من 9,300 مفتاح AWS صالح منها 526 مفتاح جذر و242 مستخدما بصلاحية AdministratorAccess عبر 817 شركة؛ مع إمكانية الاستيلاء الكامل على الحسابات أو سرقة البيانات أو تكبد فواتير تعدين العملات المشفرة

من نفّذها

الجهة: باحثو Truffle Security (اكتشاف)

الإسناد: اقتصر المسح البحثي على بيانات وصفية للقراءة فقط؛ وتنبع حالات الكشف من إيداع المطورين أسرارا في النماذج ومجموعات البيانات وSpaces والشيفرة

الدافع: البحث الأمني وإخطار المالكين

كيف حدثت

أسلوب الهجوم: أسرار مضمنة في مستودعات Hugging Face وسجل Git ومجموعات البيانات وصور Docker والسجلات وسجلات CI

السبب الجذري: بيانات اعتماد أودعت مع مخرجات تعلم الآلة من دون فحص أو تدوير أو تنبيهات ميزانية؛ ومتوسط عمر المفتاح نحو خمس سنوات

التسلسل الزمني

  1. أغسطس 2022بداية نافذة الكشف التي تتبعتها Truffle Security
  2. 10 أغسطس 2026إعادة التحقق تظهر أن 88 بالمئة من 10,616 مفتاحا كاملا ما زالت تصادق بنجاح
  3. 21 أغسطس 2026نشر النتائج؛ وAmazon تقول إنها تخطر العملاء وتحجر المفاتيح المكشوفة

الاستجابة

أخطرت Truffle المالكين الذين أمكن تحديدهم؛ وتطبق Amazon سياسات حجر؛ ونصيحة بحذف مفاتيح الجذر وتدوير بيانات اعتماد IAM القديمة
