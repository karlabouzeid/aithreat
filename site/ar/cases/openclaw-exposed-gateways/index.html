ماذا حدث

بعد الانتشار الواسع لإطار عمل الوكلاء OpenClaw، وجد باحثون بوابته مرتبطة بواجهات عامة دون مصادقة على عشرات آلاف الأجهزة، كاشفةً مفاتيح API وبيانات اعتماد وسجلات دردشة خاصة.

الأثر: بين نحو 21,000 و42,000 نسخة مكشوفة بحسب الماسح؛ وأتاحت مفاتيح API ورموز المصادقة والرسائل الخاصة المسرّبة انتحال الوكلاء واختطاف الحسابات

من نفّذها

الجهة: عمليات نشر سيئة الإعداد؛ ومهاجمون انتهازيون متعددون

الإسناد: قاست الكشف SlowMist وCensys وSecurityScorecard وShodan؛ ولم تُحدد نسبة إساءة الاستخدام اللاحقة

الدافع: سرقة بيانات الاعتماد وإساءة استخدام الوكلاء المكشوفين

كيف حدثت

أسلوب الهجوم: منفذ البوابة الافتراضي 18789 قابل للوصول من الإنترنت بمصادقة ضعيفة أو معدومة، كاشفاً متغيرات البيئة والرموز وعناصر التحكم بالوكلاء

السبب الجذري: استمع إطار العمل على جميع الواجهات افتراضياً وطلبت دروس السحابة من المستخدمين فتح المنفذ؛ ومفاتيح API طويلة الأمد مخزنة في إعدادات بنص صريح

التسلسل الزمني

  1. 27 يناير 2026SlowMist تحذر من كشف مئات مفاتيح API وسجلات الدردشة على بوابات Clawdbot العامة
  2. 30 يناير 2026إصلاح ثغرة التنفيذ عن بُعد بنقرة واحدة CVE-2026-25253 في الإصدار v2026.1.29
  3. 31 يناير 2026Censys تحصي 21,639 نسخة مكشوفة
  4. 3 فبراير 2026JFrog وThe Register وغيرهما توثق آلاف الوكلاء المكشوفين ومهارات ClawHub الخبيثة

الاستجابة

رقّع المشروع ثغرة التنفيذ عن بُعد وجعل TLS 1.3 افتراضياً للبوابة وطرح أمر تدقيق أمني؛ وحث الباحثون المستخدمين على إبقاء البوابات بعيدة عن الإنترنت
