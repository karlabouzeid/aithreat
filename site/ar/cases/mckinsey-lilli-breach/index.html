ماذا حدث

عثر الوكيل الهجومي من CodeWall على حقن SQL عبر نقاط نهاية API غير مصادق عليها في Lilli، مدعياً وصولاً للقراءة والكتابة إلى 46.5 مليون رسالة محادثة وأوامر النظام؛ ورقّعت McKinsey الثغرة خلال يوم.

الأثر: ادعاء الوصول إلى 46.5 مليون رسالة محادثة و728 ألف ملف و57 ألف حساب مستخدم و95 أمر نظام قابلاً للكتابة؛ ولم يُبلّغ عن استغلال خبيث.

من نفّذها

الجهة: وكيل الذكاء الاصطناعي الهجومي المستقل من CodeWall (إفصاح مسؤول)

الإسناد: أفصحت عنها CodeWall بنفسها؛ وأكدت McKinsey الترقيع

الدافع: بحث أمني لإثبات قدرات الوكلاء المستقلين

كيف حدثت

أسلوب الهجوم: 22 نقطة نهاية API دون مصادقة؛ وحقن SQL عبر مفاتيح JSON مدمجة في الاستعلامات، إضافة إلى ضعف في التحكم بالوصول على معرّفات المستخدمين

السبب الجذري: نقاط نهاية دون مصادقة وأسماء حقول JSON غير منقّحة في SQL، مع تخزين الأوامر والملفات والإعدادات وبيانات المستخدمين في واجهة خلفية واحدة

التسلسل الزمني

  1. فبراير 2026وكيل CodeWall يحصل على وصول للقراءة والكتابة في أقل من ساعتين في أواخر فبراير
  2. 1 مارس 2026CodeWall تبلغ فريق الأمن في McKinsey
  3. 2 مارس 2026McKinsey ترقّع نقاط النهاية المكشوفة وتوقف بيئة التطوير
  4. 9 مارس 2026CodeWall تنشر نتائجها

الاستجابة

رقّعت McKinsey الثغرة خلال يوم وأوقفت البيئة؛ ونشرت CodeWall وPromptfoo تحليلات.
