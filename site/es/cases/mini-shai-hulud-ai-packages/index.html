Qué ocurrió

El gusano de TeamPCP secuestró canalizaciones de publicación para lanzar más de 170 versiones maliciosas en npm/PyPI, robando credenciales de nube, CI y herramientas de IA, y plantando persistencia en Claude Code y VS Code.

Impacto: Más de 170 versiones maliciosas en 19 espacios de nombres de npm además de PyPI, incluidos paquetes con 1,3 M de descargas semanales; robó credenciales de GitHub, AWS, Vault, Kubernetes, npm y herramientas de IA, y plantó hooks de persistencia en Claude Code y VS Code

Quién lo provocó

Actor: TeamPCP

Atribución: Atribuido a TeamPCP por Wiz, Socket, Expel y Phoenix Security a partir de coincidencias de herramientas con campañas anteriores

Motivo: Robo masivo de credenciales (nube, CI, npm, tokens de herramientas de IA) para reventa y compromisos posteriores

Cómo ocurrió

Vector de ataque: Un pull request desde un fork contra TanStack router envenenó la caché de GitHub Actions, extrajo un token de publicación OIDC y publicó paquetes troyanizados; el gusano luego reutilizó tokens de npm robados para propagarse

Causa raíz: Colisión de caché de GitHub Actions entre PR de forks y upstream, permisos de token demasiado amplios y compilación y publicación en un mismo job, lo que derrotó al 2FA y a la publicación confiable

Cronología

  1. 10 may 2026Se crea el fork del atacante de TanStack/router; un commit huérfano planta el flujo malicioso
  2. 11 may 2026Se publican en npm y PyPI versiones maliciosas de TanStack, OpenSearch, Mistral AI y Guardrails AI
  3. 12 may 2026Socket, Wiz y Expel publican análisis; los mantenedores retiran las versiones y rotan los tokens
  4. ago 2026Un compromiso relacionado activado desde un fork afecta a openapi-react-query-codegen

Respuesta

Versiones comprometidas retiradas; TanStack publicó un análisis post mortem; los proveedores emitieron IOC y guías de limpieza para los hooks de persistencia en IDE; se instó a los usuarios afectados a rotar todos sus secretos
