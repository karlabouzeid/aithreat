Qué ocurrió

Wiz halló una base de datos ClickHouse de DeepSeek accesible públicamente que exponía más de un millón de líneas de registro, incluidos historiales de chat de usuarios, secretos de API y detalles del backend; fue asegurada tras la notificación.

Impacto: Más de un millón de líneas de registro expuestas: historial de chat de usuarios, claves secretas de API, detalles del backend y metadatos operativos; Wiz indicó que un atacante podría haber tomado el control total de la base de datos y potencialmente escalado privilegios

Quién lo provocó

Actor: Configuración incorrecta de DeepSeek; descubierta por Wiz Research (divulgación responsable)

Atribución: Configuración incorrecta evidente; descubierta y divulgada por Wiz Research, que notificó a DeepSeek antes de publicar

Motivo: Ninguno (exposición accidental); el motivo de Wiz fue la investigación de seguridad

Cómo ocurrió

Vector de ataque: Base de datos ClickHouse sin autenticación accesible en los puertos 8123 y 9000 en oauth2callback.deepseek.com y dev.deepseek.com, consultada mediante la interfaz HTTP

Causa raíz: Base de datos interna de registros ClickHouse desplegada sin autenticación y expuesta a la internet pública; datos sensibles (historial de chat, claves de API) escritos en registros en texto plano

Respuesta

DeepSeek aseguró la base de datos con rapidez tras la notificación de Wiz; no hubo declaración pública de DeepSeek sobre si alguien más accedió a los datos

Estado actual: Resuelto
