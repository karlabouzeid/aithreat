Lenovo's Lena support chatbot coaxed into XSS payload that steals agent session cookies

Cybernews used a 400-character prompt to make Lenovo's Lena chatbot emit HTML with a broken image tag that sent cookies to an attacker server, exposing support agents' sessions. Lenovo acknowledged and fixed it.

What happened

Cybernews used a 400-character prompt to make Lenovo's Lena chatbot emit HTML with a broken image tag that sent cookies to an attacker server, exposing support agents' sessions. Lenovo acknowledged and fixed it.

Impact: Session hijack of live and historical support chats was possible; no evidence of real-world exploitation

Who triggered it

Actor: Cybernews research team

Attribution: Responsible disclosure on 22 July 2025; Lenovo confirmed on 6 August

Motive: Security research

How it happened

Attack vector: Direct prompt injection requesting HTML output; unsanitised chatbot response rendered in the support interface

Root cause: No input validation or output sanitisation between the LLM and the web front end

Timeline

  1. Jul 22, 2025Cybernews discloses the issue to Lenovo
  2. Aug 6, 2025Lenovo confirms the vulnerability
  3. Aug 18, 2025Lenovo patches and Cybernews publishes

Response

Lenovo said it protected its systems after the report

Current status: Patched
