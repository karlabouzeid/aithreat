What happened

Researchers found hundreds of ClawHub skills posing as crypto and social tools that told users to install a fake 'AuthTool', delivering infostealers such as AMOS on macOS.

Impact: 341 malicious skills identified, over 100 posing as crypto tools; payloads included AMOS stealer, reverse shells and config exfiltration. Infection counts not confirmed.

Who triggered it

Actor: ClawHavoc operation (unnamed group) plus smaller unrelated uploaders

Attribution: Koi Security linked 335 of 341 malicious skills to a single coordinated operation it calls ClawHavoc; no named group

Motive: Financial: credential and crypto wallet theft via infostealers

How it happened

Attack vector: Fake Prerequisites sections in skill docs instructing users to download password-protected ZIPs or run obfuscated scripts delivering AMOS and other stealers

Root cause: Unvetted skill marketplace with no code review; users trusting install instructions for crypto and social tools

Timeline

  1. Jan 27, 2026First wave of malicious skill uploads to ClawHub
  2. Feb 1, 2026Koi Security completes audit of 2,857 skills, flagging 341
  3. Feb 4, 2026Findings published; OpenClaw adds user reporting

Response

Malicious skills removed from ClawHub; OpenClaw maintainer added a reporting feature; Koi published indicators.

Current status: Contained
