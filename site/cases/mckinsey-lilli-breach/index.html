Autonomous AI agent breaches McKinsey's Lilli chatbot platform in two hours

CodeWall's offensive agent found SQL injection via unauthenticated Lilli API endpoints, claiming read-write access to 46.5M chat messages and system prompts; McKinsey patched within a day.

What happened

CodeWall's offensive agent found SQL injection via unauthenticated Lilli API endpoints, claiming read-write access to 46.5M chat messages and system prompts; McKinsey patched within a day.

Impact: Claimed access to 46.5 million chat messages, 728,000 files, 57,000 user accounts and 95 writable system prompts; no malicious exploitation reported.

Who triggered it

Actor: CodeWall autonomous offensive AI agent (responsible disclosure)

Attribution: Self-disclosed by CodeWall; McKinsey confirmed patching

Motive: Security research demonstrating autonomous agent capability

How it happened

Attack vector: 22 unauthenticated API endpoints; SQL injection via JSON keys concatenated into queries, plus broken access control on user IDs

Root cause: Unauthenticated endpoints and unsanitized JSON field names in SQL, with prompts, files, configs and user data stored in one backend

Timeline

  1. Feb 2026CodeWall agent gains read-write access in under two hours in late February
  2. Mar 1, 2026CodeWall notifies McKinsey security team
  3. Mar 2, 2026McKinsey patches exposed endpoints and takes dev environment offline
  4. Mar 9, 2026CodeWall publishes findings

Response

McKinsey patched within a day and took the environment offline; CodeWall and Promptfoo published analyses.

Current status: Patched
