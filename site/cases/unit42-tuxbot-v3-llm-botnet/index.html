What happened

Unit 42 recovered the TuxBot v3 Evolution framework whose 61 C files carry an unremoved LLM safety disclaimer and chain-of-thought comments; about 70 percent works, including Telnet brute force and DDoS.

Impact: Operational DDoS capability; infection counts not reported. Several claimed features such as Argon2id hashing and the exploit VM were non-functional.

Who triggered it

Actor: Keksec ecosystem operator

Attribution: Unit 42 links the operator to Keksec via shared Kaitori v3.9 and AISURU dropper infrastructure; a Git log leaked an Iranian-hosted hostname.

Motive: DDoS-for-hire

How it happened

Attack vector: Telnet, SSH, HTTP and ADB scanners, exploits for 30-plus IoT families, Go C2 with DDoS panel

Root cause: LLM-generated code let a low-skill developer assemble a large framework, bugs and disclaimers included

Timeline

  1. Mar 1, 2026C2 infrastructure active from at least this month
  2. Apr 1, 2026Unit 42 sees six new samples in telemetry
  3. Jul 15, 2026Unit 42 publishes analysis

Response

Unit 42 published IOCs and noted it fixed several bugs with a few prompts, warning more polished versions likely exist.

Current status: Ongoing
