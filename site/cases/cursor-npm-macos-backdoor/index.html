What happened

Socket found three npm packages promising cheap Cursor access that stole Cursor credentials, patched Cursor's main.js with attacker code, disabled auto-update and restarted the IDE to keep remote execution inside it.

Impact: More than 3,200 downloads; infected Cursor installs ran attacker-controlled code with auto-update disabled, exposing credentials, source code and build pipelines

Who triggered it

Actor: npm accounts gtr2018 and aiide

Attribution: Published under the npm usernames gtr2018 and aiide; no further attribution

Motive: Credential theft and persistent code execution inside a developer IDE, with potential for source and CI/CD compromise

How it happened

Attack vector: Malicious npm packages advertised as tools for cheap Cursor access; install script harvested credentials, fetched an encrypted payload and overwrote files under Cursor.app

Root cause: Developers trusting unofficial npm packages to bypass subscription fees; IDE application files writable by the user and no integrity checking of patched components

Timeline

  1. Feb 13, 2025sw-cur and sw-cur1 published by gtr2018
  2. Feb 14, 2025aiide-cur published by aiide
  3. May 9, 2025Socket discloses the campaign with over 3,200 combined downloads and petitions npm for removal

Response

Socket requested removal from npm and advised victims to reinstall Cursor from a trusted source, rotate credentials and audit code for unauthorized changes

Current status: Contained
