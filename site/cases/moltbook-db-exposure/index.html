What happened

Wiz found Moltbook's Supabase database lacked row-level security, letting anyone read and write 1.5M agent tokens, 35,000 emails and private messages containing third-party API keys.

Impact: 1.5 million agent API tokens, about 35,000 owner emails and private agent messages containing third-party API keys readable and writable; any agent could be impersonated.

Who triggered it

Actor: Wiz Research and researcher Jameson O'Reilly (responsible disclosure)

Attribution: Self-disclosed by Wiz; Moltbook confirmed and fixed

Motive: Research; no malicious exploitation confirmed

How it happened

Attack vector: Supabase API key in client-side JavaScript combined with missing row-level security policies on production tables

Root cause: Vibe-coded platform shipped without row-level security, so the public anon key granted full read and write access

Timeline

  1. Jan 31, 2026Researchers discover the exposed Supabase database
  2. Feb 1, 2026Moltbook secures the database within hours with Wiz help
  3. Feb 2, 2026Wiz publishes findings

Response

Moltbook enabled row-level security and rotated tokens; Wiz deleted data accessed during research.

Current status: Patched
